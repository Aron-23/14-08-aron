# 📚 Organizador Escolar

¡Bienvenido al **Organizador Escolar**! Esta es una aplicación web sencilla y moderna diseñada para ayudar a los estudiantes a llevar un control visual de sus tareas pendientes y entregadas.

Este proyecto fue creado pensando en la simplicidad, la prolijidad y la facilidad de uso, ideal para presentaciones escolares o para estudiantes que están dando sus primeros pasos en el desarrollo web.

---

## 🚀 Características

- **Visualización Clara**: Diferenciación por colores para tareas "Pendientes" (Rojo) y "Entregadas" (Verde).
- **Diseño Moderno**: Interfaz limpia con tarjetas (cards) y efectos visuales agradables.
- **Totalmente Responsive**: Funciona perfectamente en computadoras, tablets y teléfonos celulares.
- **Sin Dependencias**: Construido 100% con HTML5 y CSS3 puro, sin frameworks ni librerías externas.

## 🛠️ Tecnologías Usadas

- **HTML5**: Estructura semántica del sitio.
- **CSS3**: Diseño, colores vibrantes y adaptabilidad (Flexbox y Grid).

## 📂 Estructura del Proyecto

```text
/organizador-escolar
│
├── index.html    # Estructura principal de la página
└── style.css     # Estilos y diseño visual
```

## 💻 Cómo usar este proyecto

1.  Clona este repositorio o descarga los archivos.
2.  Busca el archivo `index.html` en la carpeta del proyecto.
3.  Haz doble clic en el archivo para abrirlo en tu navegador preferido (Chrome, Firefox, Edge, etc.).
