📚 Organizador Escolar
📌 Descripción

Organizador Escolar es una página web sencilla creada para ayudar a los estudiantes a organizar y visualizar sus tareas escolares.

La idea surge de una problemática común: muchas veces los estudiantes olvidan las tareas pendientes o las fechas de entrega.

El proyecto permite visualizar de manera clara las tareas, sus materias, fechas de entrega y estados.

🎯 Objetivo

Crear una herramienta simple que ayude a los estudiantes a:

📖 Ver sus tareas escolares.
📅 Recordar las fechas de entrega.
📝 Diferenciar tareas pendientes y entregadas.
👀 Organizar la información de una manera clara y visual.
✨ Características
📚 Lista de tareas escolares.
🟢 Diferenciación visual de tareas entregadas.
🔴 Diferenciación visual de tareas pendientes.
📅 Visualización de fechas de entrega.
💻 Diseño adaptable a computadoras, tablets y celulares.
🎨 Interfaz simple y fácil de entender.
🚫 No requiere base de datos ni instalación de programas adicionales.
🛠️ Tecnologías utilizadas

Este proyecto fue desarrollado utilizando tecnologías web básicas:

HTML5 → Para crear la estructura de la página.
CSS3 → Para los estilos, colores, tarjetas y diseño responsive.

No se utilizaron frameworks ni librerías externas.

🚀 Cómo utilizarlo
Descargar o clonar el repositorio.
Entrar en la carpeta organizador-escolar.
Abrir el archivo index.html.
El proyecto se abrirá directamente en el navegador.

También se puede utilizar una extensión como Live Server en Visual Studio Code para visualizar los cambios automáticamente.

🎓 Problemática escolar

En el ámbito escolar, los estudiantes suelen tener varias tareas de diferentes materias y pueden olvidar alguna fecha de entrega.

Este proyecto busca resolver esa problemática mediante una interfaz sencilla donde toda la información importante se encuentra organizada en un solo lugar.
